# Image2AnkiDeck

Image2AnkiDeck は、問題・解答を画像とテキストで登録して Anki デッキ用のカードデータ（.apkg）を作成するための Web アプリです。

## デプロイリンク（GitHub Pages）

- master（本番）: https://kojikobayashi.github.io/Image2AnkiDeck/
- develop（開発）: https://kojikobayashi.github.io/Image2AnkiDeck/develop/

## 簡易な使い方

1. デッキ名を入力する
2. 問題に画像（範囲選択）またはテキスト（または両方）を入力して「問題を登録」
3. 解答に画像（範囲選択）またはテキスト（または両方）を入力して「解答を登録」
4. 2〜3 を必要なカード枚数だけ繰り返す
5. 「APKGを保存」でデッキデータをダウンロードする

## 画像アップロード（モバイル対応）

各画像エリアには「ファイルから選ぶ」と「📷 カメラで撮影」の 2 つのボタンがあります。

| ボタン | Android | iOS | デスクトップ |
|---|---|---|---|
| ファイルから選ぶ | ギャラリー | ギャラリー | ファイル選択 |
| 📷 カメラで撮影 | カメラ直接起動 | カメラ直接起動 | ファイル選択 |



1. ダウンロードした `.apkg` を Anki で開く
2. デッキをインポートしてカードを確認する
